# 📐 Simple Sine Calculator (Python)

A minimal Python program that calculates the sine of an angle using user input.  
This project was part of my exploration into basic math operations and Python modules.

---

## 🎮 What It Does

- Prompts the user for the **opposite** and **hypotenuse** sides of a right triangle.
- Calculates the sine of the angle using the formula:  
  `sin(θ) = opposite / hypotenuse`
- Prints the result in a readable format.

---

## 🧠 Features

- Uses `input()` for interactive user input.
- Demonstrates basic use of Python's `math` module (import shown, though not used directly here).
- Simple and clear logic for learning trigonometry in code.

---

## 🛠 Technologies Used

- **Python 3**
- Built-in `math` module (optional for future improvements)
